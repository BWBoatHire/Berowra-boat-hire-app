Maritime NSW Aid to Navigation

This dataset provides all known aids to maritime navigation in NSW, including both private and public channel markers. The key attribute is symbology which contains a numeric value from NSW Maritime symbolset representing the type of navigation aid.

Maritime NSW Aid to Navigation data available in the following formats:

  • csv
  • geoJSON
  • JSON
  • kml
  • shapefile

An interactive map shows the locations of Maritime NSW Aid to Navigation and data is updated weekly.
