Maritime NSW Wash Restriction Area

This dataset provides areas where generation of wash is prohibited as designated by signs along the NSW waterway. Dataset formats include:

  • csv
  • geoJSON
  • JSON
  • kml
  • shapefile

The dataset also includes an interactive map which allows for simple querying of the data and provides a visualisation of the locations. Data is refreshed on a weekly basis.
